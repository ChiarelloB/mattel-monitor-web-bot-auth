Mattel Hot Wheels Stock Monitor

This is a personal notification bot operated by the GitHub account ChiarelloB.

Purpose: monitor public availability changes for Hot Wheels vehicle products in the Mattel Creations collectors catalog and send private Telegram alerts to the operator.

The monitor reads public catalog data only. It does not sign in, create carts, reserve products, or place orders. Requests are scheduled at a low frequency and respect server retry instructions. No product data is republished by this page.

Web Bot Auth public key directory: JWKS.
